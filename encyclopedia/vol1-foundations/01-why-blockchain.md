# 1.1 从记账说起：为什么人类需要区块链

> **本章目标**：搞清楚区块链到底解决了什么问题。搞不清这个，后面所有技术细节都是背单词。
>
> **前置知识**：无。

---

## 一、一切金融的本质都是记账

你银行卡里的"10000 元"不是一堆钱躺在某个抽屉里，**它就是银行数据库里的一行数字**。

```
账户            余额
张三          10,000
李四           5,000
```

张三转 1000 给李四，银行做的事只有一件：把张三那行改成 9000，李四那行改成 6000。

钱没有移动，**只有账本被修改了**。

微信余额、支付宝、股票账户、房产证——全都是账本。整个现代金融体系，就是一套"谁有权修改哪个账本"的权力安排。

### 中心化账本的三个固有问题

| 问题 | 具体表现 |
|------|---------|
| **单点权力** | 谁掌握账本，谁就能冻结、修改、拒绝服务 |
| **单点故障** | 数据库挂了/被黑了/公司倒闭了，账本就没了 |
| **不可验证** | 你无法独立核实银行的账是不是对的，只能选择相信 |

平时这三点都不是问题——银行有监管，出事有兜底。**但在没有共同信任机构的场景里，这三点全部致命。**

跨境、跨机构、跨主权的场景就是这样：中国的银行和阿根廷的银行凭什么共用一个账本？谁来当那个能改账本的人？

## 二、要做一个"没有管理员的账本"，卡在哪

假设你想做一个所有人共同维护、没人能独裁的账本。你立刻会撞上两堵墙。

### 墙一：双花问题（Double Spending）

这是**数字资产独有的问题**，实物货币不存在。

```
一张 100 元纸币：
你给了我 → 你手上就没有了。物理世界自动保证唯一性。

一个数字文件：
你发给我 → 你手上还有一份。复制粘贴是零成本的。
```

如果"钱"就是一串数字，那么同一笔钱可以同时发给一百个人。**数字货币要成立，必须有办法阻止同一笔钱被花两次。**

中心化系统靠一个权威账本解决：银行看一眼余额，不够就拒绝。**去中心化系统没有这个权威，怎么办？**

### 墙二：拜占庭将军问题（Byzantine Generals Problem）

1982 年计算机科学界提出的经典问题【A：Lamport, Shostak, Pease 论文《The Byzantine Generals Problem》, ACM TOPLAS, 1982】：

```
几支军队围攻一座城市，必须同时进攻才能赢，同时撤退才能保命。
将军之间只能靠信使传消息。
问题：信使可能被截，将军里可能有叛徒发假消息。
在这种条件下，忠诚的将军们能不能达成一致行动？
```

翻译成账本问题：**一群互不信任、可能有人作恶、通信还不可靠的节点，怎么对"账本长什么样"达成一致？**

这个问题在中本聪之前，学术界研究了二十多年，有理论解（PBFT 等），但都需要**事先知道参与者是谁**。开放网络里谁都能随时加入，这些方案用不了。

## 三、前人的坟场

区块链不是凭空出现的，它踩在一堆尸体上。

| 项目 | 年份 | 做法 | 死因 |
|------|------|------|------|
| **DigiCash** | 1989 | David Chaum 的匿名数字现金，密码学很先进 | 【B】仍需中心化发行方，公司 1998 年破产 |
| **e-gold** | 1996 | 黄金背书的数字货币，峰值数百万账户 | 【A】2007 年美国司法部起诉，创始人认罪，业务终止 |
| **b-money** | 1998 | Wei Dai 提出，已有"工作量证明+分布式账本"雏形 | 只是设计提案，从未实现 |
| **Bit Gold** | 1998 | Nick Szabo 提出，结构与比特币高度相似 | 未解决"谁的链是对的"问题，未实现 |

**共同教训**：技术上的匿名、加密都不是难点。**难点是"谁说了算"。** 只要有一个中心化的发行方或清算方，这个点就会被攻击——技术上被黑，或者法律上被关停。

## 四、中本聪的解法：把"记账权"变成一场花钱的竞赛

2008 年 10 月 31 日，一个署名 Satoshi Nakamoto 的人发布了 9 页论文《Bitcoin: A Peer-to-Peer Electronic Cash System》【A：bitcoin.org 白皮书原文】。

它的核心不是密码学创新（用的都是现成的哈希和签名），而是一个**经济学设计**：

### 三件东西缝在一起

```
① 谁来记账？
   → 不指定。谁先算出一道没有捷径的数学题，谁记这一页。
     算题要烧真金白银的电，这叫工作量证明 (PoW)。

② 有分歧听谁的？
   → 听累计算力最多的那条链（最长链规则）。
     想改历史，你得把从那时到现在的所有算力重算一遍并超过全网。

③ 凭什么有人愿意烧电？
   → 记账成功奖励新币 + 手续费。
     而这些币要值钱，网络就必须诚实。作恶等于砸自己饭碗。
```

### 关键洞察

前人一直想用**技术**保证诚实。中本聪换了个思路：**用经济激励让作恶不划算。**

```
攻击网络的成本 = 掌握全网 51% 算力所需的硬件 + 电费
攻击成功的收益 = 双花一笔钱
攻击的副作用   = 网络信任崩塌，你手上的币和矿机一起归零

→ 算得过来的攻击者，会发现老老实实挖矿更赚钱
```

这就是为什么比特币运行了 17 年没被攻破——**不是攻不破，是攻破不划算。**

> 【推测】这一点很多科普讲不清楚。比特币的安全性不是"数学上不可能"，而是"经济上不合算"。这两者的区别在判断任何 PoW 链的安全性时至关重要：小市值 PoW 链被 51% 攻击的案例真实存在过（如 Ethereum Classic、Bitcoin Gold）【B】，因为它们的算力便宜到能租。

## 五、于是"区块链"是什么

把上面的设计落成数据结构，就是区块链：

```
区块 100          区块 101          区块 102
┌──────────┐     ┌──────────┐     ┌──────────┐
│ 上块哈希 │←────│ 上块哈希 │←────│ 上块哈希 │
│ 交易列表 │     │ 交易列表 │     │ 交易列表 │
│ 时间戳   │     │ 时间戳   │     │ 时间戳   │
│ 随机数   │     │ 随机数   │     │ 随机数   │
└──────────┘     └──────────┘     └──────────┘
```

**每个区块都包含上一个区块的"指纹"（哈希）。**

这带来一个性质：**改动任何一个历史区块，它的哈希就变了，后面所有区块的"上块哈希"就全对不上了。** 你必须把它之后的所有块全部重新计算——而每一块都要重新烧一遍电。

链越长，改写历史越贵。这就是"不可篡改"的真实含义:

> ⚠️ **"不可篡改"是个营销词，准确说法是"篡改成本随时间指数上升"。** 6 个确认之后改写比特币历史在经济上已经不现实，但这不等于数学上禁止。

## 六、区块链解决不了什么（反炒作必读）

这一节比前面所有内容都重要。**行业里 90% 的骗局，都建立在对区块链能力的夸大上。**

| 常见宣称 | 真相 |
|---------|------|
| "上链让数据不可篡改" | 只保证**上链之后**不可篡改。**上链之前**的数据是真是假，区块链一无所知 |
| "区块链能溯源商品" | 链能保证"这条记录没被改过"，不能保证"这瓶酒真的是茅台"。⚠️ **物理世界和链上世界的接口，是所有溯源项目的死穴** |
| "去中心化所以更安全" | 去中心化换来的是**抗审查**，不是抗黑客。合约有 bug 照样被掏空 |
| "区块链降本增效" | 全网每个节点重复算一遍同一件事，**比中心化数据库贵几个数量级**。它买的是信任，不是效率 |
| "区块链保护隐私" | 比特币、以太坊的账本**完全公开**。所有转账任何人可查。默认是"匿名"不是"隐私"，而且匿名极易被链上分析打破 |

**判断任何一个"区块链 + X"项目，先问一句：这件事里，谁和谁之间缺乏信任，且找不到共同信任的第三方？**

答不上来的，就是把数据库换个名字。

## 七、一句话总结

> **区块链是一套用经济激励解决"谁有权记账"的机制。它的成本极高，换来的唯一好处是：在没有共同信任机构的前提下，一群陌生人能对一个账本达成一致。**

用得着这个好处的场景，它是革命性的。用不着的，它就是个昂贵的数据库。

## 八、常见误解

**误解 1：区块链 = 比特币**
区块链是比特币的底层技术之一。后来的以太坊、Solana 结构差别很大，共识机制也完全不同。

**误解 2：挖矿是在"解密码"或"做有用的计算"**
挖矿是在**穷举随机数**，找一个让区块哈希小于某个目标值的数。这个计算本身**没有任何外部价值**，它的唯一意义就是"证明我花了电"。这是设计如此，不是浪费的意外。

**误解 3：区块链上的信息一定是真的**
链只保证**记录未被修改**。有人往链上写"我是马云"，这条记录会永久保存且不可篡改——但它依然是假的。

**误解 4：去中心化是非黑即白的**
去中心化是**光谱**，不是开关。比特币的节点数、以太坊的验证者数、某条新链的 20 个节点——差别巨大。判断一条链要问：**多少个实体串通就能改变结果？**

**误解 5：中本聪很神秘所以比特币可疑**
【无指控】中本聪身份至今未被证实。历次"我是中本聪"的主张（如 Craig Wright）均未被接受，其中 Craig Wright 于 2024 年被英国高等法院判定并非中本聪【A：英国高等法院 COPA v. Wright 判决】。创始人匿名对比特币反而是优势——**没有可被起诉、被胁迫、被收买的中心人物。**
