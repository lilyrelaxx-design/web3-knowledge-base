# 1.5 共识机制家族

> **本章目标**：搞懂各种共识机制在换什么、亏什么，以及怎么判断一条链"到底有多去中心化"。
>
> **前置知识**：[1.2](02-bitcoin.md)、[1.3](03-ethereum.md)
>
> 💡 **为什么重要**：每条公链的宣传都会说自己"又快又安全又去中心化"。**这三样不可能同时拿满。** 看懂共识机制，就能一眼看出它到底放弃了什么。

---

## 一、共识要解决的三件事

任何共识机制都必须回答：

```
① 谁有权提议下一个区块？          ← 出块权分配
② 大家怎么确认这个区块有效？       ← 验证规则
③ 出现分歧时听谁的？              ← 最终性 / 分叉选择
```

不同机制的区别，全在这三个问题的答案上。

---

## 二、不可能三角（Blockchain Trilemma）

```
          去中心化
         /        \
        /          \
       /            \
   安全性 ──────── 可扩展性
```

**同时把三个都做满，目前没有已知解法。** 每条链都是在这个三角里选了个位置。

| 维度 | 含义 | 怎么衡量 |
|------|------|---------|
| **去中心化** | 多少个独立实体参与，门槛多高 | 节点数、地理分布、**多少实体串通能改变结果** |
| **安全性** | 攻击成本有多高 | 51% 攻击成本、质押总值 |
| **可扩展性** | 每秒能处理多少、多便宜 | TPS、最终性时间、单笔成本 |

> ⚠️ **判断任何一条链，直接问这一句**：
> **"多少个实体串通，就能篡改或停止这条链？"**
> 比特币：需要控制全球过半算力。以太坊：需要控制超三分之一/过半的质押 ETH。某条 20 节点的新链：**14 个人**。

---

## 三、主要共识机制对照

### PoW（工作量证明）

```
出块权：谁先算出数学题谁出块
成本：  电费 + 矿机
作恶：  白烧电，且砸自己饭碗
代表：  Bitcoin、Litecoin、Dogecoin、Monero
```

| 优点 | 缺点 |
|------|------|
| 机制最简单，经受了 17 年实战检验 | 能耗巨大 |
| 攻击成本来自**链外**（真实世界的电和硬件），最难伪造 | 吞吐低，最终性慢（概率性） |
| 参与无需许可 | 算力向低电价地区和大矿池集中 |

**PoW 的最终性是"概率性"的**：没有哪一刻交易被官方宣布"不可逆",只是确认数越多、被推翻的概率越低。

### PoS（权益证明）

```
出块权：按质押量加权随机选中
成本：  锁定的资本 + 机会成本
作恶：  质押被罚没（slashing）
代表：  Ethereum、Solana、Cardano、Avalanche
```

| 优点 | 缺点 |
|------|------|
| 能耗低约 99.9%【A】 | 【B】"富者愈富"批评：质押收益按持有量分配 |
| 可实现**经济最终性**（明确的不可逆点） | 攻击成本来自**链内资产**，存在循环论证质疑 |
| 罚没让攻击直接损失本金 | 质押高度集中于少数服务商（Lido、交易所） |

**PoS 的一个真实批评**：链的安全性由代币价值支撑，而代币价值又部分来自链的安全性。**这个循环在币价崩盘时是否会失效，尚未被极端行情充分检验。**

### DPoS（委托权益证明）

```
出块权：持币人投票选出固定数量的出块节点（如 21 个）
代表：  EOS（已边缘化）、TRON、早期 BNB Chain
```

**本质是用去中心化换性能。** 21 个节点当然快，但也意味着 **14 个节点串通就能控制网络**。

> 【推测】DPoS 在 2018 年前后很火，现在基本被视为"高性能但明确中心化"的方案。它没有消失——TRON 至今是稳定币转账量最大的链之一——只是**没人再假装它是去中心化的了**。

### BFT 系（拜占庭容错）

```
出块权：轮流或选举产生提议者
确认：  节点之间多轮投票，超过 2/3 同意即最终确定
特点：  ⭐ 单区块最终性 —— 一旦确认，立刻不可逆，不需要等确认数
代表：  Cosmos(Tendermint)、Hyperliquid(HyperBFT)、Sui、Aptos
```

| 优点 | 缺点 |
|------|------|
| **即时最终性**，交易所可以秒到账 | 节点间通信量随节点数**平方级增长** |
| 延迟极低，适合交易场景 | 所以节点数天然被限制在几十到几百 |
| | 超过 1/3 节点作恶或掉线，网络直接停摆 |

**HotStuff 是这一系最重要的现代论文**（2018 年，学术公开发表）。Hyperliquid 的 HyperBFT 基于它【A】——顺带说明一个常见误解：多个项目基于同一篇公开论文**不构成抄袭**（见 [Hyperliquid 案例](../../cases/01-hyperliquid.md#共识算法说明)）。

> 💡 **为什么 Perp DEX 都选 BFT 系**：交易场景不能接受"等 6 个确认"。清算引擎要在 0.2 秒内完成，**必须要单区块最终性**。这就是为什么 Hyperliquid 宁可只用约 20 个验证者也要走这条路——**它明确选择了速度，放弃了去中心化**。

### PoH / 其他混合方案

**Solana 的 PoH（历史证明）** 常被误解成一种共识机制。准确说：**PoH 是一个可验证的时钟，不是共识**。它让节点无需来回通信就能对"事件顺序"达成一致，Solana 真正的共识仍是 PoS（Tower BFT）。

## 四、横向对照表

| 机制 | 代表 | 最终性 | 节点数量级 | 放弃了什么 |
|------|------|--------|-----------|-----------|
| PoW | Bitcoin | 概率性（6确认≈1小时） | 数万节点 | 性能、能耗 |
| PoS | Ethereum | 经济最终性（约13分钟） | 【B】数十万验证者 | 部分抗审查性（质押集中） |
| DPoS | TRON | 快 | 21–27 | **去中心化（明确）** |
| BFT | Cosmos / Sui | **单区块，即时** | 几十–几百 | 去中心化、抗停摆能力 |
| BFT | Hyperliquid | **0.2 秒** | 约 20 | 去中心化（最激进的取舍） |

> ⚠️ **表中的节点数量级请勿直接对外引用具体数字**——这些数字随时在变，且不同来源统计口径不同。要用请查当期数据并注明时点。

## 五、怎么判断一条链的真实去中心化程度

不要看宣传，看这五个问题：

```
1. 有多少个独立验证者？      ← 不是"节点"，是能出块的
2. 前几大验证者占多少份额？   ← 33% 和 51% 是两条关键线
3. 谁能停掉这条链？          ← BFT 系超 1/3 掉线就停摆
4. 跑一个节点需要什么门槛？   ← 硬件成本、质押门槛、是否需要许可
5. 客户端有几种实现？        ← 只有一种实现 = 一个 bug 全网瘫
```

### 两条关键的阈值线

| 阈值 | 含义 |
|------|------|
| **33%** | BFT 系：控制 1/3 可以**阻止**网络出块（活性攻击） |
| **51%** | PoW：可以双花和审查 |
| **67%（2/3）** | BFT 系：可以**任意篡改**（安全性攻击） |

> 💡 **对 BD 的意义**：一条链号称"高性能"时，先查它的验证者数量和准入方式。**性能的来源如果是"节点少"，那它本质上是一个多方共管的数据库，不是去中心化网络。** 这不一定是坏事（Hyperliquid 就靠这个赢了），但要说清楚，别让它冒充别的东西。

## 六、一句话总结

> **共识机制没有最优解，只有取舍。PoW 用真实世界的能耗买安全，PoS 用锁定资本买效率，BFT 用节点数量买速度。判断一条链的唯一有效问题是：多少个实体串通能改变结果？**

---

## 七、常见误解

**误解 1：PoS 比 PoW 更先进，PoW 已经过时**
两者的安全模型**性质不同**。PoW 的攻击成本来自链外（电、硬件），PoS 来自链内（代币）。**PoW 在"极端市场崩溃时是否还安全"这个问题上答案更明确。** 这是取舍不是代际。

**误解 2：TPS 高 = 技术好**
TPS 极容易通过减少节点数、放宽验证来堆高。**看 TPS 必须同时看节点数和最终性时间**，否则等于比较"跑车"和"火车"谁快。

**误解 3：节点数 = 去中心化程度**
"全节点"和"验证者/出块节点"是两回事。一条链可以有一万个只读全节点和 20 个出块节点——**决定权在后者**。

**误解 4：BFT 系的链更安全，因为有即时最终性**
即时最终性是**用户体验**的优势，不是安全性优势。BFT 系的代价是节点少、以及**超过 1/3 节点出问题就整链停摆**（Solana 历史上多次全网停机是相关案例【B】）。PoW 链理论上永远不会"停机"。

**误解 5：51% 攻击只是理论**
【B】小市值 PoW 链上真实发生过多次（Ethereum Classic、Bitcoin Gold 等）。**攻击可行性取决于攻击成本 vs 收益，不取决于机制本身。**

**误解 6：质押收益是"利息"**
不是。质押收益的来源是**新增发行 + 交易费**，本质是网络在支付安全成本。名义收益率要减去通胀稀释才是真实收益（见[卷二 2.11](../README.md)、[方法 01 第七章](../../methods/01-project-fundamentals.md#74-通胀与真实收益)）。
