# 1.4 私钥、助记词、钱包

> **本章目标**：搞懂"你的币到底存在哪"，以及为什么绝大多数人亏钱不是亏在行情上。
>
> **前置知识**：[1.2](02-bitcoin.md)、[1.3](03-ethereum.md)
>
> ⚠️ **这是全书最该认真读的一章。** 前面几章讲错了你只是理解偏了，这一章讲错了你会真的丢钱。

---

## 一、最反直觉的一句话：钱包里没有币

```
❌ 错误理解：币存在钱包里，钱包丢了币就没了
✅ 正确理解：币在链上，钱包里只有「证明这些币是你的」的那把钥匙
```

**钱包 = 钥匙串，不是保险箱。**

所以：
- 你的手机丢了 / 钱包 App 删了 → **币还在链上，一分没少**。用助记词在任何一个钱包里恢复就行
- 你的助记词泄露了 → **别人可以在世界任何地方把币转走**，你换手机、改密码、卸载 App 全都没用

**这一条决定了后面所有安全操作的逻辑。**

---

## 二、三层结构：助记词 → 私钥 → 地址

```
助记词（12 或 24 个英文单词）
   │  单向推导，不可逆
   ↓
私钥（一串 64 位十六进制数）
   │  单向推导，不可逆
   ↓
公钥
   │  单向推导，不可逆
   ↓
地址（0x开头 / bc1开头，可以随便给别人）
```

**箭头只能从上往下走，不能反推。** 这是整个密码学体系的根基。

| 层级 | 别名 | 能干什么 | 泄露后果 |
|------|------|---------|---------|
| **助记词** | 种子、seed phrase、恢复短语 | 恢复整个钱包的**所有**账户和所有链 | ☠️ 全部资产归零，无法挽回 |
| **私钥** | private key | 控制**单个**地址 | ☠️ 该地址资产归零 |
| **地址** | address、公钥地址 | 收款用 | ✅ 无害，随便发 |

### 一个必须建立的直觉

**助记词 > 私钥。** 很多人以为"我只是把助记词给了客服，私钥没给"——**助记词能推出所有私钥**，给助记词等于给了全部。

> 🚫 **绝对规则，无一例外**：
> **任何人、任何机构、任何情况下索要你的助记词或私钥，100% 是诈骗。**
> 交易所不会要，钱包官方不会要，"官方客服"不会要，"资产核验"不会要，"解冻账户"不会要。
> **没有任何一个合法流程需要你的助记词。**

## 三、钱包分类

### 按联网状态分

| 类型 | 是什么 | 安全性 | 适合 |
|------|--------|--------|------|
| **热钱包** | 联网设备上的软件钱包（MetaMask、OKX Wallet、Phantom） | 中 | 日常交互的小额资金 |
| **冷钱包 / 硬件钱包** | 私钥永不触网的独立设备（Ledger、Trezor、OneKey、Keystone） | 高 | 长期持有的大额资金 |
| **纸钱包** | 把助记词写在纸上 | 取决于保管 | 备份，不是日常使用 |

**硬件钱包的核心原理**：交易在电脑上组装好，送进设备里签名，**签好的结果送出来，私钥永远不出设备**。所以即使你的电脑中了木马，攻击者也拿不到私钥。

> ⚠️ **硬件钱包不是万能的。** 它防的是"私钥被偷"，**防不了"你自己签了一笔恶意交易"**（见第五节）。设备上的确认屏幕要一个字一个字看，这是它最后的防线。

### 按谁掌握私钥分（**最重要的分法**）

```
托管（Custodial）              自托管（Non-custodial）
你在交易所的资产                你的 MetaMask / 硬件钱包
私钥在平台手里                  私钥在你手里
"Not your keys, not your coins"
```

| | 托管 | 自托管 |
|---|------|--------|
| 忘记密码 | ✅ 可以找回 | ❌ 助记词丢了就永久丢失 |
| 平台跑路/倒闭 | ☠️ 资产可能归零（Mt.Gox、FTX） | ✅ 不受影响 |
| 被冻结/审查 | ⚠️ 可能 | ✅ 没人能冻结 |
| 操作失误 | ⚠️ 客服可能能帮 | ❌ 转错地址无法追回 |
| 门槛 | 低 | 高，责任全在自己 |

**这是一个没有标准答案的取舍。** 自托管把"信任平台的风险"换成了"你自己出错的风险"——而**统计上，普通人自己出错的概率并不低**。

> 💡 **实务建议**：分层。日常交易的钱放交易所（方便、能找回），长期持有的大额放硬件钱包（抗平台风险）。**不要把所有鸡蛋放一个篮子，也不要盲目相信"自托管一定更安全"。**

### 新一代方案

| 类型 | 原理 | 现状 |
|------|------|------|
| **多签（Multisig）** | 需要 N 把钥匙里的 M 把才能动钱（如 3/5） | 机构和 DAO 金库的标准配置。Safe(原 Gnosis Safe) 是主流 |
| **MPC 钱包** | 私钥被拆成碎片分布在多方，**从不完整存在于任何一处** | 交易所和机构托管广泛采用 |
| **账户抽象 / 智能合约钱包** | 钱包本身是合约，可以设社交恢复、每日限额、免 Gas 等 | ERC-4337 标准；以太坊 Pectra 升级的 **EIP-7702** 让普通 EOA 也能临时具备合约能力【A】 |

> 【推测】账户抽象是解决"私钥体验太反人类"的主流方向。**"丢了助记词就永久失去资产"这个设计，是 Web3 大规模采用的最大障碍之一**，社交恢复这类方案在长期看几乎必然普及。

## 四、助记词怎么备份（实操）

### 该做的

```
✅ 手写在纸上，至少两份，放在两个物理隔离的地方
✅ 大额考虑金属助记词板（防火防水）
✅ 定期验证：用备份在一个空钱包里恢复一次，确认抄对了
✅ 考虑分片保存（如 2/3 分片），但方案要简单到你三年后还记得
```

### 绝对不要做的

```
❌ 截图 / 拍照        → 自动同步到云相册，云账号被黑 = 币没了
❌ 存在备忘录 / 网盘  → 同上
❌ 发给自己微信/邮箱  → 同上
❌ 打字进任何输入框（除了官方钱包的恢复界面）
❌ 让任何人「帮你保管」
❌ 记在脑子里就不备份 → 【B】历史上大量永久丢币案例出于此
```

> ⚠️ **最常见的死法不是被黑，是自己弄丢。** 助记词抄错一个词、纸条被家人当垃圾扔掉、搬家找不到了——这类案例远多于黑客攻击。

### 一个容易忽略的问题：你不在了怎么办

自托管资产**没有继承机制**。你不告诉任何人，这笔钱就永久消失。这不是危言耸听，是自托管的固有代价。方案（多签、分片给不同亲属、律师保管封存件）都有取舍，但**至少要有一个方案**。

## 五、比丢私钥更常见的死法：授权钓鱼

**这是现在最主流的被盗方式，而且硬件钱包挡不住。**

### 原理

在以太坊上花你的代币，需要你先给合约一个**授权（approve）**。

```
正常流程：
你在 Uniswap 换币 → 授权 Uniswap 合约可以动你的 USDT → 交易执行

钓鱼流程：
你点了假网站 → 它请求授权 → 你签了名
→ 它拿到了「可以无限额转走你 USDT」的权限
→ 你钱包里的钱它随时可以搬走，不需要再问你
```

**关键点：你签的不是转账，是授权。** 签的时候钱没动，你以为没事，实际上门已经开了。

### 常见变种

| 手法 | 表现 |
|------|------|
| **无限授权** | 授权额度是天文数字，等于永久开门 |
| **Permit / Permit2 签名钓鱼** | 只让你"签个名"不花 Gas，看起来人畜无害，实际是授权 |
| **setApprovalForAll** | NFT 的全集合授权，一签整个系列都能被搬走 |
| **假空投领取页** | "领取空投"按钮实际是授权请求 |
| **地址投毒** | 给你转 0 元，制造一个和你常用地址前后几位相同的记录，等你从历史记录复制粘贴 |

### 防御

```
1. 签名之前一个字一个字读弹窗，看不懂就不签
2. 硬件钱包上的确认屏是最后防线 —— 别闭着眼按确认
3. 定期用 revoke.cash / 各链的 approval checker 清理旧授权
4. 大额资产钱包「只收不交互」，另开一个小额钱包做日常交互
5. 官网只从收藏夹进，永远不点搜索广告位和推特链接
```

> 💡 **第 4 条是最有效的单条建议**。把"保管"和"交互"两个功能拆到两个钱包，绝大多数钓鱼就失效了。

## 六、一句话总结

> **币在链上，钱包只是钥匙串。助记词是最高权限，泄露即归零，且没有任何合法流程需要它。而现在最常见的被盗方式不是私钥泄露，是你亲手签下了一份自己没看懂的授权。**

---

## 七、常见误解

**误解 1：钱包 App 卸载了币就没了**
不会。币在链上。用助记词在任何兼容钱包里都能恢复。

**误解 2：把币"提到钱包"是把币搬到了手机里**
不是。是把链上资产的控制权从交易所的地址转到了你的地址。**币从来没离开过链。**

**误解 3：硬件钱包 = 绝对安全**
硬件钱包保护私钥不外泄，**不保护你免于自己签恶意交易**。授权钓鱼对硬件钱包一样有效。

**误解 4：交易所比自托管更危险**
不一定。合规大所的安全团队和保险机制，多数情况下强于个人。**Mt.Gox 和 FTX 是真实教训，但"自己保管把助记词弄丢"也是真实教训。** 两种风险性质不同，不是简单的谁更安全。

**误解 5：同一套助记词在不同链上是不同的钱**
同一套助记词可以派生出比特币、以太坊、Solana 等多条链的地址。**它们共享同一个"根"**——所以助记词泄露是**全链、全资产**的泄露，不只是某一条链。

**误解 6：地址转错了可以找回**
【A】区块链交易不可逆。转错地址、转错链（如把 ERC-20 转到只支持 BEP-20 的地址）**基本无法追回**。转账前小额试一笔是唯一有效的保险。

**误解 7："官方客服"在推特/Telegram 私信我**
【B】**正规项目方和交易所从不主动私信用户**。所有主动联系你的"客服"默认是诈骗。这条几乎没有例外。
