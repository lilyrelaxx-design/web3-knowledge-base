## 本卷的阅读顺序

1.1 → 1.2 → 1.3 是**必须按序读**的三章，后面互相独立可以跳读。

```
1.1 为什么需要      ← 建立问题意识
 ↓
1.2 比特币的答案     ← 第一个可行解，及其代价
 ↓
1.3 以太坊的答案     ← 第二个方向，及其代价
 ↓
1.4-1.9 展开细节
```
