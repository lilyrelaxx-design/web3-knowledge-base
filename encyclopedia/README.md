## 一、这本书的信息规范（**先读这一节**）

你提的最重要的要求是"信息来源必须有事实依据，传闻单独标注"。这套标记贯穿全书，每一条事实性陈述后面都会带标记。

### 1.1 事实分级（沿用知识库既有的[来源三级制](../methods/03-research-writing.md#八信息分级与写作准确性硬规则)并扩展）

| 标记 | 含义 | 来源要求 | 能不能拿去对外讲 |
|------|------|---------|----------------|
| `【A】` | 一级事实 | 官方文档、官方公告、法庭文件、监管文书、链上可验证数据、审计报告 | ✅ 可以直接引用 |
| `【B】` | 二级事实 | 主流媒体报道，且**至少两家独立交叉验证** | ✅ 需注明"据媒体报道" |
| `【C】` | 线索 | 单一来源、行业自媒体、KOL 文章、社媒转述 | ⚠️ 只能当线索，不能当依据 |
| `【传闻】` | 未证实 | 无可靠来源但行业内广泛流传 | ❌ 讲的时候必须说"这是传闻" |
| `【已证伪】` | 曾流传已被推翻 | 保留条目 + 推翻它的证据 | ✅ 用于反驳再次传播 |
| `【推测】` | 本书作者的判断 | 明确区分于事实，附推理依据 | ⚠️ 说明这是个人判断 |

**硬规则**（违反即算写错）：

1. 数字必须带**时点**和**口径**。写"市场份额 70%"不算数，要写"未平仓合约份额 ~70%（2026-08）"
2. 同一指标不同来源冲突时，**列区间 + 注明分歧**，不要私自选一个
3. `【传闻】`条目必须写清**最早出处**和**流传范围**，写不出来就不收录
4. 未被起诉的人**不得使用"涉嫌"**二字
5. 已知会变的数字（价格、市值、TVL）不写进正文，写进[快照表](#附录d-数据快照表)，正文只写数量级和结构

### 1.2 人物志的特别规则

写活人有法律风险，这一卷单独一套规矩：

| 标记 | 用在什么情况 |
|------|------------|
| `【法律事实·已定罪】` | 有生效判决，注明罪名、刑期、法院 |
| `【法律事实·已认罪】` | 有认罪协议 |
| `【法律事实·被起诉】` | 有正式起诉书，**注明尚未定罪** |
| `【法律事实·调查中】` | 有官方确认的调查，**不等于有罪** |
| `【法律事实·已和解】` | 民事/行政和解，通常"不承认不否认" |
| `【无指控】` | 该人未被任何机构指控，用于反驳传闻 |

**红线**：不写未经证实的私德指控；不写未被官方确认的调查；不做人身评价，只写"做了什么 + 后果是什么"。

## 四、写作纪律（给未来的自己）

1. **先写目录里的一章，写完就核查一遍来源，再写下一章。** 不要批量生成后统一核查——那样一定核查不动。
2. **每一章结尾必须有"一句话总结"和"常见误解"两块。** 小白记住的往往就是这两块。
3. **数字全部进附录 D。** 正文写"日均交易量在百亿美元量级（2026-08，见附录D）"，不写具体数字。
4. **不确定就标不确定。** 宁可写"这一点公开信息不足"，也不要用模糊表述糊过去。
5. **每章写完在 [`README.md`](../README.md) 的快速索引里加一行。**
