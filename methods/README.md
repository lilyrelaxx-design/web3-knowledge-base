# 分析方法

**可复用的框架**——换个项目照样能用的东西。这是整个库最该反复翻的部分。

## 现有文件

| 文件 | 用途 | 什么时候翻 |
|------|------|-----------|
| `01-project-fundamentals.md` | 项目基本面完整手册（指标详解 + 造假识别 + 红旗清单 + 数据源） | 评估任何项目 |
| `02-due-diligence.md` | 尽调五步法 + 资金盘识别（含两个案例） | 怀疑是骗局时 |
| `03-research-writing.md` | 研报写作规范 + 赛道调研 16 环节框架 + 来源三级制 | 动笔写东西前 |

**01 和 02 的分工**：01 判断正经项目值不值，02 判断是不是骗局。

## 什么放这里

- 判断方法、评估框架、计算公式（如解锁压力 = 90天解锁额 ÷ 日均交易量）
- 写作和信息处理规范
- 从踩坑中提炼出的**可复用**教训——注意是"可复用"，只对某个项目成立的结论放 `research/`

## 写法要求

- **给基准数字**：说"DAU/MAU 低"没用，要写">20% 健康，<5% 是任务地址"
- **给造假手法**：任何指标都要配一节"怎么被造假"，只教怎么读不教怎么被骗是半成品
- **配案例**：抽象规则后面跟一个真实案例，方法论才立得住
- 新方法论如果来自某次具体调研，标注来源和日期（如"RGB赛道调研 2026-07-28 固化"）
