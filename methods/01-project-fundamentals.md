> 用途:配合每日基本面练习(Q1–Q5框架)。
> 结构:第一章是基础概念速成(日报里高频出现的词);第二章起是指标详解,每个指标按「是什么 → 数据在哪看 → 怎么读(带基准数字) → 怎么被造假 → 迷你案例」展开。

# 第一章 基础概念速成

> 这一章解决"日报里的词看不懂"的问题。按出现频率排序。

## 1.1 链上 vs 链下
- **链上(on-chain)**:发生在区块链上、任何人可查的行为——转账、合约交互、质押。链上数据不可篡改,是最可信的数据源。
- **链下(off-chain)**:CEX内部的交易、团队的口头承诺、Excel里的数据。CEX的交易在它自己的数据库里撮合,只有充提币才上链——所以CEX交易量是可以随便报的,链上DEX交易量至少留了痕迹(虽然也能刷,见后文)。

## 1.2 智能合约(Smart Contract)
部署在链上的自动执行程序。DeFi协议本质就是一组智能合约:你把钱存进合约,合约按写死的规则运作。意义:①规则透明可审计;②合约有bug就会被黑,这是DeFi最大的死法之一(对应Q5)。

## 1.3 AMM 与 LP(理解DEX的钥匙)
- **AMM(自动做市商)**:DEX不用订单簿,靠一个资金池+定价公式(如 x*y=k)自动报价。你用USDT换ETH,本质是往池子里放USDT、从池子里拿ETH,价格随池内比例变化。
- **LP(流动性提供者)**:往池子里存入两种代币的人,赚交易者付的手续费。DEX的TVL主要就是LP存进来的钱。
- **无常损失(Impermanent Loss)**:LP的隐性成本——两种代币价格分化时,LP的资产组合会比"单纯拿着不动"更差。为什么重要:很多DEX靠代币补贴覆盖LP的无常损失,补贴一停LP就撤,TVL崩塌。

## 1.4 质押(Staking)与LST
- **质押**:锁定代币参与网络安全(PoS链)或协议运作,换取收益。
- **质押率**:已质押量/流通量。公链质押率高(如50%+)通常读作"持有者长期信心+流通抛压减少",但也意味着解除质押潮可能成为集中抛压。
- **LST(流动性质押代币)**:质押ETH得到stETH这类凭证,既拿质押收益又保持流动性。LST可以再存进借贷协议——这就是TVL重复计算的主要来源。

## 1.5 Gas
在链上做任何操作要付的手续费,付给验证者。意义:①Gas收入是公链的"营业收入",最真实的需求指标;②Gas太贵会杀死小额用户,这是L2存在的理由。

## 1.6 L1 / L2 / Rollup
- **L1**:主链(Ethereum、Solana、BNB Chain、TON)。
- **L2**:建在L1之上的扩容层(Arbitrum、Base),交易在L2执行、结果批量提交回L1,便宜10–100倍。
- 读L2数据时注意:L2的"利润" = 用户付的Gas − 它提交回L1的成本。有些L2交易量巨大但每笔收0.001美元,收入极薄。

## 1.7 预言机(Oracle)
把链下价格喂给链上合约的服务(Chainlink为主)。借贷协议靠预言机价格决定清算。**预言机被操纵 = 协议被掏空**,历史上大量攻击走这条路。尽调时看:项目用的是Chainlink还是自建预言机(自建=风险加分项)。

## 1.8 跨链桥(Bridge)
把资产从A链挪到B链的通道。本质是"A链锁定+B链铸造映射资产"。桥是被黑金额最大的品类(Ronin 6.2亿美元、Wormhole 3.2亿美元)。项目主要资产若依赖某座桥,桥的安全性要进Q5。

## 1.9 稳定币的三种类型
- **法币抵押型**(USDT/USDC):公司拿真实美元资产背书。看点:储备构成、审计方、冻结权。
- **超额抵押型**(DAI):锁150%的加密资产铸100%的稳定币。看点:抵押品构成。
- **算法型**:靠机制而非足额资产维持锚定。UST的400亿美元崩盘就是这一类。日报里出现"算稳"两个字,默认高危。

## 1.10 衍生品基础(Perp相关日报高频)
- **永续合约(Perp)**:没有到期日的期货,散户加杠杆的主要工具。
- **OI(未平仓量)**:市场上还没平掉的合约总量。OI快速上升+价格上涨 = 新多头进场;OI高位+价格滞涨 = 随时可能多杀多。
- **资金费率(Funding Rate)**:多空双方互相支付的费用,正费率=多头拥挤。极端正费率经常出现在局部顶部。
- **清算(Liquidation)**:杠杆仓位保证金不足被强平。大额清算会引发连环踩踏,这是"插针"行情的来源。

## 1.11 空投(Airdrop)与撸毛
项目向早期用户免费发代币。**撸毛(farming)**:用大量地址刷交互骗空投。后果:空投前的用户数据严重失真,空投后留存断崖。看到"某项目活跃地址暴涨"先问一句:它有没有空投预期?

## 1.12 代币标准与合约权限
- ERC-20(以太坊系代币标准)、BEP-20(BNB Chain)等。
- **合约权限**:owner能不能增发?能不能暂停交易?能不能拉黑地址?貔貅盘(只能买不能卖)就是合约权限滥用。工具:GoPlus、Token Sniffer一键检测。

# 第二章 TVL(总锁仓量)

**是什么**:锁在协议合约里的资产总价值(美元计),DeFi协议的"存款规模"。

**数据在哪看**:DefiLlama → 搜项目名。页面上直接有:TVL曲线、链分布、代币构成、是否含double counting的开关。

**怎么读**:
- **趋势 > 绝对值**:持续增长 > 高位下滑。把时间轴拉到1年看形态。
- **币本位TVL**:DefiLlama可切换ETH/BTC计价。美元TVL涨可能只是币价涨;币本位涨才是真的有新资金。
- **构成拆解**:点开token分布。稳定币和主流币占比高 = 扎实;自家代币占比>50% = 虚胖,币价跌TVL跟着蒸发,还会引发"币价跌→TVL跌→信心跌→币价再跌"的螺旋。
- **跨赛道不可比**:借贷的TVL是抵押品,DEX的TVL是做市资金,LST的TVL是质押量。只在同赛道内排名。
- **MC/TVL比率**:流通市值/TVL。同赛道内,比率低=单位锁仓对应的估值便宜。借贷/DEX历史常见区间大约0.5–2,显著高于同行要有额外理由(叙事、增速)支撑。

**怎么被造假**:
- **激励刷量**:高补贴吸来的雇佣兵资金。验证法:DefiLlama看该协议的incentives数据(如有),或对比历次激励活动结束前后30天的TVL变化。
- **重复计算**:stETH存进Aave,Lido和Aave都记了一遍。看数据时确认double counting开关状态。
- **自己人撑盘**:金库或关联地址存入。链上看前几大存款地址的来源。

**迷你案例**:2021–2022年多条新公链用数亿美元激励计划把生态TVL在几个月内拉到几十亿美元,激励退坡后TVL普遍回撤70–90%。判断当时唯一有效的问题是:"如果明天停止补贴,这些钱为什么留下?"——答不出来的,后来都走了。

# 第三章 市值、FDV与供应结构

## 3.1 三个基础数字
- **MC(流通市值)** = 流通量 × 现价:市场当前的真实定价。
- **FDV(完全稀释估值)** = 总供应 × 现价:所有代币都流通时的估值。
- **MC/FDV比率**:核心健康指标。

**数据在哪看**:CoinGecko项目页(Market Cap、FDV都直接列出);流通计划看CoinGecko的Tokenomics标签或Tokenomist。

**怎么读**:
- MC/FDV ≈ 1:全流通,无解锁抛压,估值"实"。老币(BTC、ETH、大部分2017–2020的币)多是这种。
- MC/FDV < 0.3:超过70%的筹码还没进市场,未来持续解锁。
- MC/FDV < 0.15:典型"低流通高FDV"结构,2024年后新币的普遍病灶——VC轮估值层层抬高,开盘FDV几十亿,散户在最高点接盘,之后两年靠解锁持续放血。
- 横向比较时**统一用FDV口径**,否则低流通的币会显得"便宜"。

## 3.2 流通量的水分
"流通"≠"在散户手里"。逐项排查:
- 基金会/生态基金持有但计入流通的部分
- 做市商借币(通常有回售期权条款)
- 前10/前100地址集中度:区块浏览器 → Holders页,手动剔除合约地址(质押合约、锁仓合约)和交易所冷钱包后再算。**剔除后前10地址>30% = Q5记一笔**。

**迷你案例读法**:一个FDV 20亿、MC 2.4亿(MC/FDV=0.12)的新币,日均交易量1500万美元,未来6个月每月解锁4000万美元——每月解锁量≈2.7天的全部交易量。这个结构下,任何利好拉升都会被解锁方当成出货窗口。这套算术要练到条件反射。

# 第四章 收入与费用

**核心区分**:
- **Fees(费用)**:用户付的总费用。
- **Revenue(收入)**:费用中归协议自己(或代币持有者)的部分。
- 差距可以是100%:Uniswap长年费用巨大,但历史上全部归LP,协议收入为0——这也是UNI代币价值捕获争议的核心。

**数据在哪看**:
- DefiLlama → Fees页:大部分协议的日/月费用和收入,可排序。
- Token Terminal:标准化后的收入、P/F、P/S,适合横向对比,像看上市公司财报。

**怎么读**:
- 收入是Q1最硬的证据:**用户肯付钱 = 需求是真的**。
- **看熊市收入**:牛市链上收入普遍暴涨3–10倍,把时间轴拉到包含2022–2023年,看低谷期还剩多少,那才是基本盘。
- **P/F、P/S(市值/年化费用、市值/年化收入)**:只在同赛道比。成熟DeFi协议P/F常见个位数到几十倍;新叙事项目可以到几百倍——高倍数买的是增速预期,增速一旦证伪,估值和数据双杀。
- **收入的分配去向**:回购?销毁?分红给质押者?进金库?这直接连到Q2——收入很高但和代币无关的协议,业务成功≠代币成功。

**怎么被造假**:
- 刷量制造虚假费用(配合第六章识别)。
- 把自家代币的激励发放包装成"生态收入"。
- 宣传只讲Fees绝口不提Revenue。

# 第五章 用户指标

## 5.1 活跃地址(DAU/MAU)
**数据在哪看**:Artemis(跨链对比最方便)、Dune(搜项目名找社区dashboard)、Token Terminal。

**怎么读**:
- **地址≠人**:一人可控几百地址,空投预期期间尤其严重。
- **DAU/MAU粘性比**:>20%健康(用户每周来1–2次以上);<5% = 大量一次性任务地址。
- **人均费用** = 日费用/DAU:人均费用趋近于0(如<0.01美元)= 机器人或任务党为主。真实用户是肯付钱的。
- **地址增长的形态**:自然增长是缓坡;活动/空投驱动是尖峰。尖峰后的回落幅度暴露真实留存。

## 5.2 留存(Retention)
新用户30/60/90天后还活跃的比例。Dune上搜"项目名 + retention"常有现成看板。
- 消费级/GameFi项目30日留存<5%基本判死缓。
- **空投后断崖**是最常见死法:发币前MAU百万级,发币后三个月跌90%——历史上多个明星链游和任务平台走完了这条路。练习时遇到"某项目用户暴涨",第一反应查它的空投/积分活动时间表。

## 5.3 真实需求三问
1. 没有任何代币激励时,还有没有人用?
2. 激励占用户总收益的比重多大?(>80% = 雇佣兵盘)
3. 历史上激励退坡时,数据掉了多少?

# 第六章 交易量

**数据在哪看**:DEX看DefiLlama → Volumes;CEX看CoinGecko(注意它对交易所有信任分级);代币在各交易所的量看CoinGecko项目页Markets标签。

**怎么读**:
- **Volume/TVL(资本周转率)**:DEX核心效率指标。同样1亿TVL,日周转50% vs 5%,前者的流动性被真实使用。头部DEX日均常见10%–100%+,长期<5%说明流动性闲置(靠补贴硬撑)。
- **量价费匹配**:交易量大但费用低得不成比例 → 刷量嫌疑。
- **交易所分布**:量集中在一两家小所 = 高危;主流大所占比高 = 相对可信。

**怎么识别wash trading(刷量)**:
- 少数地址贡献大部分交易量(Dune可查地址集中度)
- 单笔金额高度规律(整数、固定值反复出现)
- 交易量只在激励/排名活动期间存在,活动结束归零
- 买卖单时间间隔极短且成对出现
- **Listing视角特别提醒**:项目方在冲刺上所前刷量做数据是行业常规操作,上所前3个月的交易量数据默认打折看待,重点看更早期的自然量。

# 第七章 代币经济学(Q2的主战场)

## 7.1 分配结构
**数据在哪看**:项目文档/白皮书的Tokenomics章节;CryptoRank和Tokenomist有标准化图表。

**判读基准**:
- 团队+投资人 ≤ 30–40%:常规
- 团队+投资人 > 50%:红旗
- 社区/生态占比高但用途模糊("生态基金"没有明确的发放规则和多签管理)= 实际是团队二号钱包
- 公募/空投占比极小 + VC占比大 = 筹码结构对散户极不友好

## 7.2 解锁表(Vesting)
**概念**:
- **Cliff(悬崖期)**:完全锁定期,通常TGE(代币生成事件)后6–12个月。
- **线性解锁**:cliff后按月/按秒匀速释放,通常持续2–4年。
- **TGE解锁比例**:上线当天就流通的份额。

**数据在哪看**:Tokenomist(原TokenUnlocks)、CryptoRank → Unlocks。

**核心算术**(练到条件反射):
```
解锁压力 = 未来90天解锁的美元价值 ÷ 日均交易量
```
- < 3天交易量:可消化
- 3–10天:显著压力,警惕解锁日前后的行情
- > 10天:结构性抛压,任何反弹都是出货窗口
另外看**解锁给谁**:解锁给质押奖励池(大概率继续锁)和解锁给VC(成本极低,大概率卖)完全是两回事。

## 7.3 价值捕获(Value Accrual)——Q2的核心问题
按强度排序:
1. **回购销毁/费用分红**:协议收入直接买币销毁或分给质押者。最强管道。看点:分配比例写死在合约里,还是"治理可随时改"。
2. **质押安全/质押准入**:代币质押保障网络或换取协议使用资格。需求与网络价值正相关。
3. **使用抵扣**:用代币付费打折。有需求但"用完即抛",持币动机弱。
4. **纯治理**:只有投票权。历史证明这是最弱赋能,大量纯治理币长期跑输其底层协议的业务增长。
5. **无**:代币和业务之间没有任何管道。Q2直接答"否"——业务再成功,代币也只是空气。练习中会震惊地发现这类项目的数量之多。

## 7.4 通胀与真实收益
- **年通胀率**:新增供应/现有供应。>20%的高通胀需要等量的真实需求对冲,否则纯稀释。
- **Real Yield(真实收益)**:名义APY − 代币通胀稀释。用自家代币通胀发的"120% APY",本质是印钱发给你,你赚的是后来者的接盘。
- 判别口诀:**收益来源如果不是"别人付的费用",就是"自己印的钞票"**。

# 第八章 团队、融资与金库(Q4)

## 8.1 融资
**数据在哪看**:RootData(中文友好,融资数据全)、CryptoRank、Messari。

**怎么读**:
- 融资额、轮次、估值变化:种子轮估值到最新轮估值抬了多少倍?VC成本价 vs 当前价差距太大 = 解锁即卖动机强。可用"轮次估值 ÷ 总供应"粗算VC的每币成本。
- **领投机构质量**:一线基金(如Paradigm、a16z crypto等)领投是信号但不是保票——一线VC投的项目也大量归零,它只说明项目"及格线以上",不说明"会成功"。
- **警惕纯撒网轮**:几十家机构每家投一点,没有领投 = 没人做过深度尽调。

## 8.2 团队
- 实名+可验证履历 > 化名但业内知名 > 完全匿名(匿名+高合约权限=高危组合)
- 前项目的下场:做过rug/归零盘的团队,复发率极高
- **GitHub活跃度**:仓库commit频率与人数。注意区分真实开发和刷commit(改README也算commit),看代码变更量和贡献者数量更准。

## 8.3 金库与Runway
- 金库构成:稳定币+主流币占比高 = 真钱;全是自家代币 = 纸面富贵,熊市时"千万美元金库"能缩水95%
- Runway = 金库真实价值 ÷ 月支出:<18个月且无收入 = 下轮融资或死亡
- **数据在哪看**:DAO类项目用DeepDAO,或直接找到公开的金库地址在区块浏览器/Debank看构成

# 第九章 流动性与市场结构(Q5)

- **±2%深度**:在中间价上下2%范围内的挂单总量。CoinGecko项目页的Markets标签有各交易所的±2% depth数据。深度<10万美元的币,一笔5万美元的市价单就能砸出长针,极易被操纵。
- **深度/市值比**:市值上亿但全网深度只有几十万美元 = 市值是"虚的",根本卖不出这个价。
- **流动性分布**:只在无信誉小所有量 → 数据可信度整体降级。
- **做市商条款**:上所项目通常和做市商签"借币+期权"协议,做市商有权在某价格买入借的币。这批币在期权行权价上方是潜在卖压。公开信息少,但大额做市商钱包的链上动向可追踪。
- **持仓集中度**(排除合约与交易所地址后):前10 > 30%红旗;前100 > 70%红旗。另外看大户的**近期动向**:Arkham/Nansen可标注聪明钱和机构地址的增减仓。

# 第十章 安全与合约风险(Q5)

- **审计**:有没有?谁审的(Tier 1: Trail of Bits、OpenZeppelin、Spearbit等)?审计报告里的高危项修了没有?注意:**审计≠安全**,被黑的协议大多数"有审计"。
- **审计的时效性**:审计后合约又升级过 = 审计失效。
- **Bug赏金**:有没有Immunefi赏金计划,金额多大(赏金额度侧面反映团队对安全的投入)。
- **合约权限检测**:GoPlus / Token Sniffer一键查——能否增发、能否暂停、能否拉黑、owner是否多签、是否放弃权限。**单一EOA地址持有全部权限 = 一把私钥决定生死**。
- **被黑历史**:REKT News数据库查协议的事故史,以及事故后的赔付表现(赔没赔、怎么赔的,比没出过事更能看出团队品性)。
- **依赖风险**:协议依赖的预言机、跨链桥、底层LST,任何一环出事都会传导。

# 第十一章 竞品对比方法(把Q5做扎实)

单个项目的数据没有意义,**同赛道排名才有意义**。标准流程:
1. DefiLlama按赛道(Categories)拉出同类前10
2. 做一张四列表:TVL/主指标、费用、MC/FDV、FDV
3. 算两个相对值:**市占率**(项目主指标 ÷ 赛道总量)和**估值倍数**(FDV ÷ 年化费用)
4. 回答:它凭什么从现有玩家手里抢份额?(更便宜/更快/新机制/新链先发)
5. 反问:头部玩家抄它这个功能需要多久?(能被一周抄走的"创新"不是护城河)

这一步的产出直接可复用到你的Listing研究框架里。

# 第十四章 红旗清单(Q5快速排查)

**结构类**
- [ ] MC/FDV < 0.15(低流通高估值)
- [ ] 未来90天解锁 > 10天日均交易量
- [ ] 团队+VC分配 > 50%
- [ ] VC成本价与现价差 > 10倍且临近解锁

**数据类**
- [ ] TVL中自家代币占比 > 50%
- [ ] 收益率主要靠自家代币通胀(无Real Yield)
- [ ] DAU/MAU < 5% 或人均费用 ≈ 0
- [ ] 交易量集中在1–2家小所
- [ ] 激励活动结束后核心数据回撤 > 70%(查历史)
- [ ] 排除合约地址后前10持仓 > 30%

**代币类**
- [ ] 无任何价值捕获机制(纯治理或纯"生态通证")
- [ ] 合约可增发/可暂停/可拉黑,且owner为单一地址
- [ ] 上所前3个月交易量异常放大(刷量冲榜嫌疑)

**团队类**
- [ ] 完全匿名 + 高合约权限
- [ ] 金库无多签、无披露、全是自家代币
- [ ] 前项目有rug或归零史
- [ ] GitHub近90天无实质commit

**任何项目命中 ≥ 3条 → Q5答案基本写好了。**

# 第十五章 练习使用方式

每天流程(5分钟):
1. 从日报挑一条没完全看懂的消息
2. 判断它触碰哪个指标 → 翻对应章节
3. 用「怎么读」下判断,用「怎么被造假」做一次反向质疑
4. 写三句话(影响谁 / 意味着什么 / 接下来会怎样)
5. 对照别人的解读,差异记一行

知识库是地图不是课本,不用背。遇到没覆盖的概念记到下方「待补充」,攒够几条迭代一版。
