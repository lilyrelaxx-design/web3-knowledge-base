# 项目尽调方法论 + 资金盘案例分析

> 来源：CocoCat、CaryPact/BOT Chain 两个实际案例分析整理

---

## 一、项目尽调五步法

遇到任何项目方找你们交易所谈合作/上线，5分钟跑一遍：

1. **确认项目是否真实存在**：搜项目名 + 官网域名，排除纯空气项目
2. **找独立第三方信源**：搜"项目名 + scam/跑路/资金盘/传销"，不要只看项目自己怎么说
3. **查代币经济模型**：搜"项目名 + token/tokenomics/airdrop"，看代币用途是否清晰、是否和其他项目"撞名"
4. **查团队/融资透明度**：用 RootData 等行业数据库查团队、融资、投资方是否可验证
5. **拆解收益机制算账**：拿到项目方公布的收益分配方案，验证两条公式：
   - 日化收益% × 365 = 年化收益% → 超过50%即高度怀疑，超过100%基本判定不可持续
   - 分润结构里有没有"层级"（V1-V10/一级二级返佣）→ 这是区分"真实收益分享"和"传销佣金"的分水岭

**技术叙事真假验证法**：把项目宣传里的核心技术词（如"超算协议"）拿去开发者文档里搜，看是否真的有对应的技术实现。如果宣传词在技术文档里完全找不到，说明这个故事只存在于营销层面，和底层技术没有工程关联。

## 二、案例一：CocoCat（DePIN 隐私社交 App）

**项目结构**：P2P 中继网络 + 聊天 + 钱包 + 应用市场（"Substations"），声称零服务器架构、隐私加密、45万+节点覆盖142国家。

**独特点（增长机制，非技术）**：把 DePIN 赛道门槛降到最低——同类项目 Helium 需买实体硬件（~400-500美元），CocoCat 只需下载 App、零成本、零 KYC 即可"参与"。

**真实性质**：第三方反诈渠道（项目合作网等）明确将其标记为"云矿机挖币/质押生息"资金盘，"挖出来的虚拟币毫无价值，全是空气币"。变现机制（质押挖矿+邀请码拉新返佣）把一个真实存在的 DePIN 叙事，套上了资金盘惯用壳子。

**结论**：技术叙事真实存在（DePIN赛道不是凭空捏造），但具体执行和变现方式已被独立信源标记为资金盘，建议远离。

## 三、案例二：CaryPact / BOT Chain（"算力资产化协议"）

**结构关系**：BOT Chain 是底层公链（PoSA共识，EVM兼容，技术文档显示是平庸但真实的标准架构，高度类似BSC），CaryPact 是 BOT Chain 孵化的官方生态应用，专门负责卖节点收钱，CA代币与BOT代币深度绑定（CaryPact可分得BOT Chain 80% Gas费）。

**关键证据**（来自项目方自己发的资料包，非猜测）：

- **节点销售**：超算节点1000U(限3000个)/量子节点5000U(限500个)/创世节点10000U(限300个)，**推荐节点奖励5% USDT**（直接现金返佣，传销最核心特征）
- **CA代币模型**：总量2.1亿枚，22年释放完，每日产出分静态60%（算力挖矿42%+PoS质押18%）+ 动态37% + DAO 3%
- **级别分红表V0-V10**：个人投入500U-20000U + 团队业绩1万U-2倍V9，解锁30%/10%/5%分润比例，等级可叠加——标准多级分销MLM佃酬计划
- **资金流向**：入金90%进"国库"（不可验证去向），10%回购销毁；CA卖出滑点5%（1.8%回流质押池+3.2%节点分红）——质押收益资金来源写明是"卖出滑点+动态奖金结余"，无外部真实收入
- **线下组织**："营运中心/工作室补贴政策"明确要求场地面积、团队人数（1000人/100人以上社群）、"社区讲师"、月业绩门槛——这是传销组织管理语言，非Web3技术项目运营语言
- **真实收入来源**：节点销售总盘约850万U现金，一次性确定到账；CA代币挖矿产出是零成本印钱，不是项目方的核心现金来源
- **代币"实用价值"**：CA只能在系统内部质押/交易/分红，无任何外部消费场景，需求完全依赖新人接盘；"币价上涨逻辑"五条理由全部建立在内部资金循环和延迟卖出心理设计上，没有一条是外部真实需求
- **价格机制**：项目方自己用国库资金搭建CA/BOT底池，同时是发行方和做市商，可短期人为托住价格曲线制造"从不下跌"的营销素材

**额外红旗**：同一条链存在"BOT Chain"/"Bohr Chain"/"BOHR"多名混用，疑似规避负面记录的马甲操作；团队/资方信息（"TRON与原腾讯核心工程团队"、"瑞典NIX基金会"等）均为无法独立验证的机构挂名。

**结论**：有完整书面文件自证的传销/资金盘结构，不存在"早期阶段"辩解空间。

## 四、通用红旗清单（两个案例共同特征）

```
□ 节点/算力/矿机"限量发售"制造稀缺感
□ 多级返佣结构（V1-V10 / 一级二级佣金）
□ 日化收益设上限但年化换算超过50%
□ 团队/融资信息查无实据，只有机构名+金额，没有可验证姓名
□ 技术宣传词在官方开发文档里找不到对应实现
□ 邀请码/推荐码是核心增长机制
□ 线下"营运中心/工作室/社区讲师"组织架构
□ 代币唯一用途是系统内部质押/交易，无外部消费场景
□ 项目方自建流动性池，自己控制价格表现
```

可借鉴（不违法、对BD有用）的部分：叙事包装（具体数字+视觉化表达）、区域化密集路演节奏、降低参与摩擦的产品设计思路。不可借鉴：多级分销佣金结构、不可持续收益承诺、模糊团队信息。
