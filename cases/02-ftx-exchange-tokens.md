# FTX事件 + 交易所平台币（Backpack/BP）

> 写给刚接触 Web3 的新人——用最简单的话说清楚

---

## 一、FTX 事件：加密行业的"暴雷银行"

### 先打个比方

想象你把钱存进了一家银行。

你以为钱放在你的账户里，随时能取出来。

结果有一天你去取钱，柜台告诉你："不好意思，钱没了。"

然后你发现——这家银行其实一直在偷偷把你的存款拿去赌博，赌输了，跑路了。

**这就是 FTX 干的事。**

---

### FTX 是什么

```
FTX = 当时全球第二大加密货币交易所
创始人 = Sam Bankman-Fried（大家叫他 SBF）

2019年创立，2022年崩盘

高峰期：每天处理几十亿美元的交易
用户数：超过100万
```

看起来是一个庞大、正规、值得信任的交易所。

---

### 它是怎么崩的

**关键在于：SBF 同时拥有两家公司**

```
FTX（交易所）← 保管用户存款的地方
Alameda Research（对冲基金）← SBF 自己的投资公司
```

这两家公司名义上是分开的，实际上是一个人的。

**SBF 做了什么**：

```
第一步：把用户存在 FTX 的钱，偷偷转给 Alameda 去投资
第二步：Alameda 拿这笔钱去做高风险投资，亏光了
第三步：用户以为自己的钱还在账户里，其实早就没了
```

这就像银行行长把你的存款偷偷拿去买股票，亏了，但账户里显示的数字还是正常的，直到你去取钱的那一天。

---

### 崩盘过程（2022年11月，只用了5天）

```
11月2日  某媒体曝光：Alameda 的资产大部分是 FTX 自己发的代币（FTT）
         → 相当于"你说你有钱，但你的钱是你自己印的"

11月6日  币安 CEO 赵长鹏（CZ）发推特：
         "我们要卖掉所有 FTT 代币"
         → 等于公开宣布：我不信任 FTX

11月6-8日 用户恐慌，争相提款
          3天内提款需求超过 60亿美元
          FTX 根本付不出来

11月8日  币安说"考虑收购 FTX 来救它"
          翻开账本后，当天宣布放弃
          "问题太大了，我们救不了"

11月11日 FTX 正式宣布破产
```

从第一条新闻到破产，只用了**9天**。

---

### 结局

```
SBF 被捕，引渡美国接受审判
2023年11月：7项罪名全部成立
2024年3月：判处 25年监禁

受害用户：超过100万人
损失金额：约 80亿美元
```

---

### 这件事为什么重要——它改变了整个行业的规则

**FTX 之前**：大家默认交易所是安全的，存进去的钱就在那里。

**FTX 之后**：没有人再无条件信任交易所了。

```
行业被迫改变：

① 储备金证明（Proof of Reserves）成为标配
   每个正规交易所都要定期公开链上数据
   证明"你存的钱确实还在我这里"

② 监管全球加速
   各国政府开始认真立法管理交易所
   "有牌照"从加分项变成了基本要求

③ 链上交易所开始受关注
   用户开始倾向于"资金放在自己钱包里"的去中心化交易所
   Hyperliquid 的崛起，FTX 事件是重要背景之一
```

---

### 一句话记住

> FTX = 加密行业的"暴雷银行"。老板把用户的钱偷去赌博，亏光了，100万用户的钱没了，老板进了监狱。这件事之后，"交易所有没有合规牌照、有没有储备金证明"成了判断一个平台靠不靠谱的基本标准。

## 二、什么是交易所平台币

### 打个比方

你去星巴克，有星巴克会员积分。

积分可以换咖啡、打折、提前知道新品。持有积分越多，你在星巴克享受的权益越多。

**交易所平台币就是这个逻辑**——只不过"积分"本身也可以在市场上买卖，价格随交易所的发展而涨跌。

```
交易所越做越大 → 平台币越值钱
                  （更多人需要它来享受折扣）

交易所出问题   → 平台币暴跌
                  （FTT = FTX 的平台币，FTX 崩了，FTT 归零）
```

---

### 行业里的平台币历史

```
BNB  = 币安的平台币  → 随着币安成为全球第一，从几分钱涨到最高700美元
OKB  = OKX 的平台币  → 随着 OKX 全球扩张持续上涨
FTT  = FTX 的平台币  → FTX 崩盘后直接归零
```

**结论**：平台币是"押注这个交易所能不能做大"的工具。交易所死了，代币就没了。

## 三、Backpack 和 BP 代币分析

### Backpack 是什么

一个从 Solana 生态起家的新兴交易所，目前在合规性上是行业里做得最认真的之一。

---

### 团队——最重要的判断基础

```
创始人：Armani Ferrante
  ─ Solana 早期核心开发者
  ─ 创造了 Anchor 框架（Solana 上几乎所有 DeFi 项目都用它，
    相当于 Solana 生态的"地基工具"）
  ─ 曾在 Alameda Research 工作，FTX 崩盘前就已离开

联合创始人：Can Sun
  ─ FTX 的前总法律顾问（相当于 FTX 的"首席律师"）
  ─ FTX 崩盘后，他选择对 SBF 出庭作证
  ─ 现在在 Backpack 专门负责合规
  ─ 意义：亲眼见过 FTX 怎么出问题的人，
    来做"保证我们不重蹈覆辙"的工作
```

**为什么团队很重要？** 因为可以查证。真实的名字、可验证的履历，和"TRON与原腾讯工程师联合研发"的匿名团队是完全不同的东西。

---

### Backpack 经历过的考验

```
2022年9月  FTX 投资 Backpack 2000万美元
2022年11月  FTX 崩盘（距投资仅2个月）
            ↓
            很多同期拿过 FTX 投资的项目跟着倒了
            Backpack 没有

2024年2月   重新拿到融资：Placeholder VC 领投 1700万美元
2025年9月   收购 FTX EU 的欧洲合规牌照
            （FTX 留下的合法资产，被 Backpack 捡了过来）
2026年3月   发行 BP 代币
```

**主要投资方突然暴雷，还能活下来并继续融资扩张**——这是产品真实存在的最好证明。

---

### BP 代币——为什么说它"设计干净"

#### 最大的不同：团队拿了 0%

```
大多数平台币的分配方式：
  团队拿 20%
  投资人拿 20%
  社区/用户拿 60%

结果：代币一上市，团队和投资人手里有大量代币
     价格一涨他们就卖，用户高位接盘

BP 的分配：
  团队：0%
  投资人：0%
  用户/社区：100%
```

这意味着**没有人能靠"内部人拿的便宜代币"来砸你**。

---

#### 代币用来做什么（真实的用途）

```
质押 BP，可以获得：

① 交易手续费打折（最低接近 0）
   ─ 手续费是真实的钱，这个折扣有真实价值

② 美元余额额外 3% 年化收益
   ─ 交易所用你的存款产生的真实收益

③ 入金出金免手续费

④ 质押满1年 → 获得在公司 IPO 时将 BP 换成公司股票的权利
```

最后一条是整个行业的创新：

```
普通平台币：代币 → 只能在这个平台内用
BP：代币 → 质押满1年 → 可换成真实公司股权

这相当于：你持有星巴克积分，
但积分可以在星巴克上市时换成星巴克的真实股票
```

---

#### 代币怎么慢慢释放的（里程碑解锁）

```
BP 总量 10亿枚

发行当天释放：25%（全部给用户，空投）
剩余 75%：不是按时间释放，是按"做到了什么事情"才释放

比如：
  拿到欧洲合规牌照 → 释放一批，直接发给用户
  进入美国市场   → 释放一批，直接发给用户
  达到某个交易量 → 释放一批，直接发给用户
```

这个设计的巧妙之处：

```
传统设计：
  投资人的币1年后自动解锁 → 到期必然出货 → 用户被砸
  不管项目做没做事，时间到了就能拿钱

BP 的设计：
  交易所做到了真实进展 → 才能解锁 → 解锁的币直接给用户
  每次解锁 = 一个实际业务成果的奖励
  而不是内部人拿钱的借口
```
