# 工作实务

日常工作（交易所 BD、推特运营、小红书 BD 招募、内容生成）中沉淀的方法论和经验。

## 文件划分

| 文件 | 内容 |
|------|------|
| `bd-playbook.md` | 交易所 BD 实务：谈判、上币流程、合作模式、返佣、做市商对接 |
| `twitter-ops.md` | 推特运营：涨粉策略、发帖规则、内容风格、数据复盘 |
| `xhs-ops.md` | 小红书运营：BD 招募、账号管理、文案技巧、平台规则 |
| `content-creation.md` | 内容生产：科普写作、配图、多平台分发 |
| `kb-management.md` | 知识库管理：在线查看、推送、自动同步机制、网页版手动搬运 |

新领域出现时新建文件并更新 README.md。

## 记录原则

- 记"为什么这样做"和"踩过什么坑"，不记流水账
- 每条知识点标注日期，方便回溯
- 与 Web3 概念相关的深度内容放编号文件，这里只放"怎么干活"
