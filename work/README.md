## 和 methods/ 的区别

`methods/` 是**分析方法**（怎么判断一个项目），`work/` 是**执行方法**（怎么把活干完）。
研报写作规范属于分析方法，已移到 `methods/03-research-writing.md`。

## 记录原则

- 记"为什么这样做"和"踩过什么坑"，不记流水账
- 每条知识点标注日期，方便回溯
- 与 Web3 概念相关的深度内容放 `basics/`，这里只放"怎么干活"
