# DeFi 基础概念

---

## 什么是 DeFi

把传统银行的功能写成代码，没有中间人。代码自动执行，无法干预，全球任何人都能用。

---

## DEX（去中心化交易所）

**传统交易所**：你挂单 → 交易所撮合 → 成交，交易所保管你的钱。

**DEX（如Uniswap）**：用**资金池（AMM）**替代撮合。

```
资金池：有人存入 100万USDT + 100万等值ETH
你买ETH → 往池子扔USDT → 池子吐出ETH
买的人多 → ETH变贵（池子里ETH少了）
价格由公式自动决定，不需要人撮合
```

**流动性提供者**：往池子里放钱的人，赚取每笔交易手续费。

---

## 借贷协议（如Aave）

### 存款方（出借人）
```
存入 USDT → 自动赚取年化利息 → 随时可取出
利率由代码根据借款需求自动调整（借的人多，利率涨）
```

### 借款方：必须超额抵押

**为什么必须超额抵押？**
链上没有身份，无法查征信，代码不认识你，必须先押东西才能借钱。

```
押 1500美元的ETH → 才能借 1000 USDT
抵押物 > 借款额（防止跑路）
```

### 清算机制
```
押了1500美元ETH，借了1000 USDT
ETH价格暴跌 → 抵押物缩水到1100美元
触发警戒线 → 系统自动卖掉ETH还债
```
全程自动，无人工干预。

## 稳定币

DeFi里"不波动的钱"，有两种：

| 类型 | 例子 | 机制 | 信任对象 |
|------|------|------|----------|
| 中心化 | USDT、USDC | 公司背书1:1美元储备 | 信任公司 |
| 去中心化 | DAI | 链上超额抵押算出1美元 | 信任代码 |

---

## 收益聚合器（如Yearn）

自动帮你找当前收益最高的协议，利率变了自动迁移资金。

**类比**：链上的"智能理财产品"，你什么都不用做。

---

## DeFi的可组合性（乐高积木）

```
示例：一份资金同时在三个地方赚钱
1. 把ETH存入Aave → 得到aETH（存款凭证）
2. 拿aETH去Uniswap做流动性 → 赚手续费
3. 拿流动性凭证去借更多钱
```

收益放大，风险也放大。

## 对BD的意义

```
DEX交易量     → 判断一条链的活跃度
借贷协议TVL   → 判断资金有没有留在这个生态
稳定币规模    → 判断生态的"造血能力"

这三个数据告诉你：这条链值不值得重点投入资源去谈合作
```
