# 基础知识

概念和原理，**不带时效性**。判断标准：这条知识一年后还成立吗？成立就放这里。

## 现有文件

| 文件 | 主题 |
|------|------|
| `01-bitcoin-rgb.md` | 比特币不可编程的原因、RGB 协议、客户端验证 |
| `02-rollup-l2.md` | 以太坊扩容、Rollup 原理、Arbitrum 挑战期 |
| `03-defi.md` | DEX/AMM、借贷、稳定币、收益聚合、可组合性 |

## 什么放这里 / 什么不放

| 放 | 不放 |
|----|------|
| 协议怎么运作、机制为什么这样设计 | 某项目现在市值多少、进展到哪一步 → `research/` |
| 一类东西的通用原理 | 某个具体项目的深度拆解 → `cases/` |
| 概念定义、术语解释 | 怎么分析项目的框架 → `methods/` |

## 写法要求

- **先讲清"为什么会有这个东西"**，再讲它怎么运作——只讲机制不讲动机的笔记，过两个月自己也看不懂
- 有对比对象的尽量做对比表（RGB vs Arbitrum、三类稳定币）
- 涉及具体项目现状的内容加日期标注，或直接链到 `research/` 对应档案
- 后续如发现内容有误，**用修正表保留原文对照**（见 `01-bitcoin-rgb.md` 末尾），不要直接删——错在哪本身就是知识
