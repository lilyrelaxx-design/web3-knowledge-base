# 各大交易所打新（Launchpad/Launchpool）现状调研

> 调研日期：2026-08-02 | 来源：全网调研（Exa + 官方页面）

## 核心结论（先说结论）

1. **传统 Launchpool 整体降温**：锁平台币/BNB 挖新币的模式各家均在缩减，Binance Launchpool 已显示「敬请期待」。
2. **打新入口换道三叉路**：
   - **持仓快照型空投**（Binance HODLer、Gate HODLer）——快照期在 Earn 里有币即可，无需主动锁仓；
   - **积分/行为型**（Binance Alpha、Gate Alpha Points / Futures Points / CandyDrop）——靠交易量/链上行为刷分换额度；
   - **上币奖池 + 交易赛**（Bybit Token Splash、KuCoin 上币活动、Binance Trading Tournament）。
3. **代币化美股 / Pre-market / IPO Access 成新战场**：Binance bStocks、OKX Unified Tokenized Stocks、Gate IPO Access、Bitget 美股期权 Pre-market，是 2026 年「打新」最热的细分方向。
4. **Gate 当前最活跃**：Launchpool 同时有 3 个池在跑（累计 365 期），是目前参与门槛最低、频率最高的平台。

## 对我的工作的启示

- 打新不再是「锁仓挖矿」一条路，分散精力到积分刷量（Alpha）和快照持仓更省心。
- Gate 当前最值得优先开户/资金配置；Bitget PoolX 是备选。
- 代币化美股/Pre-market 打新节奏快、需要提前看官方上币公告，可订阅各平台 Telegram 公告频道。
